## normal mode

w - jump word
J - Join line
u - undo
0 - start line
$ - end of line
i - insert mode
a - insert mode after cursor

o - insertline on next line

# shell (zsh / bash)

Ctrl-A - jump to the beginning of the line
Ctrl-K - kill (cut) the rest of the line
Ctrl-Y - yank (paste) it back
